next-query cachea datos del servidor por clave en el **App Router de Next.js** y los revalida por clave. Envuelves un fetch, una llamada al ORM o cualquier código de servidor en `query()`, y llamas a `revalidate()` con la misma clave cuando los datos cambian. Mientras ejecutas `next dev`, un panel lista cada query de tu app y revalida cualquiera de ellas con un clic.

## Vistazo rápido

Cachea por clave en una página:

```tsx title="app/products/[id]/page.tsx"
import { query } from '@angelitolm/next-query'

export default async function Page({ params }: { params: Promise<{ id: string }> }) {
  const { id } = await params
  const product = await query(['products', id], () => db.product(id), { revalidate: 60 })
  return <h1>{product.name}</h1>
}
```

Revalida por clave en una server action:

```ts title="app/actions.ts"
'use server'
import { revalidate } from '@angelitolm/next-query'

export async function renameProduct(id: string, name: string) {
  await db.rename(id, name)
  revalidate('products') // ['products'] y todo lo que cuelga de él
}
```

Mira cada query desde el layout:

```tsx title="app/layout.tsx"
import { NextQuery } from '@angelitolm/next-query'

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        {children}
        <NextQuery />
      </body>
    </html>
  )
}
```

## Qué obtienes

- **Caché por clave**: la clave es un array de strings y números, y es también el nombre con el que revalidas.
- **Revalidar por prefijo**: `revalidate('products')` cubre `['products', '1']`, `['products', '2']` y cualquier otra clave que cuelgue de él.
- **Un panel de desarrollo con barras de frescura**: cada clave con su estado, una barra que cuenta hacia atrás hasta quedar obsoleta, sus datos y un botón ↻.
- **Next 15 y 16**: App Router y React 19, en ambos.

<Callout type="tip" title="Pruébalo sin instalar nada">
  La [demo en vivo](./demo) ejecuta el panel real con queries simuladas: revalida una tarjeta, revalida un prefijo entero, mira cómo las barras cuentan hacia atrás.
</Callout>

<Callout type="note" title="Solo desarrollo, en el caso del panel">
  `<NextQuery />` no renderiza nada fuera de desarrollo, y sus server actions se niegan a ejecutarse. `query()` y `revalidate()` son la propia librería: se ejecutan en todas partes, en desarrollo y en producción.
</Callout>
